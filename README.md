# GitReminder

A simple web app that helps developers quickly search, browse, and copy common Git commands — no more endless Googling.

## Why This Exists

When learning or using Git, developers often forget commands. GitReminder is a quick-reference tool that helps you find the right command in seconds. It's especially useful for beginners who are still building muscle memory with Git.

## Features

- Search Git commands by keyword
- Filter commands by category (Setup, Branching, Remote, etc.)
- Copy any command with one click
- Clean, readable interface
- Instant results as you type

## Tech Stack

- **HTML** — page structure
- **CSS** — styling and layout
- **JavaScript** — logic and interactivity

No frameworks, no build tools — just the fundamentals.
